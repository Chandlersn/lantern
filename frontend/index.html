随手记

灵感碎片

所有随手记都在这里。状态：原料（待孵化）/ 孵化中 / 已孵化（已长成知识条目）。双击卡片可编辑内容、标题、标签；点「孵化成知识」→ AI 结合知识库相关内容生成碰撞创作草稿，你微调后「确认入库」才真正进入知识库。

知识图谱

默认铺节点、隐藏连线；点节点展开关联并聚焦局部，双击打开阅读页。概念不进图谱，其关联作为后端桥接推荐，在文章节点详情页显示。

节点详情

连线默认隐藏。点一个节点即可展开它的关联连线并查看详情；双击节点直接打开阅读页。

自动核对记录

写入 / 编辑后自动扫描关联，每天三时段独立核对，新联系与近重复留在此处。时间线合并引擎核对与系统消息。

判断方式

系统可以用简单规则，也可以调用真实的大模型来判断。切换会重新评估所有内容。

「按意思找」和「该连未连」的质量取决于向量。当前接入的模型若没有 embedding 接口会自动回退本地向量；接入支持 embedding 的模型后，点这个按钮一键升级为真实语义向量。

网页接口 · /api/kb/*

POST /api/kb/add 保存并判断
POST /api/kb/query 按关键词找
POST /api/kb/neighbors 找相似内容
POST /api/kb/search 按领域筛选
POST /api/kb/position 只判断不保存
POST /api/kb/relate 关联图
POST /api/kb/context 资料包
POST /api/kb/traverse 关联漫游
GET /api/kb/schema 当前设置
GET /api/kb/state 总览
GET /api/kb/edges 可能的关联
POST /api/kb/calibrate 自动核对
POST /api/kb/mode 切换判断方式
GET /api/kb/backlinks 谁引用了它
GET /api/kb/similar 按意思找（向量）
GET /api/kb/axes 细分领域表
POST /api/kb/link · /api/kb/unlink 手动互链
POST /api/kb/import_axes 导入方向表
GET /api/kb/suggest_links 该连未连候选
POST /api/kb/delete 删除条目（自动备份）
POST /api/kb/backup · GET /api/kb/backups 快照
